# Customer Churn Analysis

## Project Overview
This project analyzes customer churn behavior using the Telco Customer Churn dataset.  
The goal is to identify key churn drivers, customer retention patterns, and business insights that can help reduce customer loss in subscription-based businesses.

This analysis simulates a real-world business scenario where a company wants to improve customer retention and reduce churn rates.

---

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Data Visualization
- Basic Retention Analysis

---

## Dataset
Dataset used: Telco Customer Churn Dataset from Kaggle.

The dataset contains customer information such as:
- Contract type
- Payment method
- Internet service
- Monthly charges
- Customer tenure
- Churn status

---

## Analysis Performed

### 1. Churn Overview
- Calculated overall churn rate
- Compared churned vs retained customers

### 2. Contract Type Analysis
- Analyzed churn across:
  - Month-to-month contracts
  - One-year contracts
  - Two-year contracts
- Found that month-to-month customers had the highest churn rate

### 3. Internet Service Analysis
- Compared churn rates between DSL, Fiber Optic, and No Internet customers
- Fiber optic customers showed higher churn behavior

### 4. Payment Method Analysis
- Analyzed customer churn by payment method
- Electronic check users had higher churn levels

### 5. Paperless Billing Analysis
- Compared churn behavior between customers using paperless billing and those who do not

### 6. Tenure Analysis
- Examined customer lifetime trends using tenure data
- Customers with shorter tenure were more likely to churn

---

## Key Insights
- Customers with month-to-month contracts are significantly more likely to churn
- Short-tenure customers show higher churn risk
- Fiber optic customers have higher churn rates
- Electronic check payment method is associated with increased churn

---

## Business Recommendations
- Encourage long-term contracts through discounts or loyalty programs
- Improve onboarding experience for new customers
- Investigate customer satisfaction among fiber optic users
- Offer incentives for automatic payment methods
- Develop retention campaigns targeting high-risk customer groups
